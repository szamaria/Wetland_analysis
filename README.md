This repo includes codes for 1) classifying wetlands into low and high inundation and connected and disconnected categories, and 2) determining the WET_FR value for disconnected wetlands developed in Zamaria et al. (2026; in prep) for the purposes of evaluating the impact of different classes of wetlands on P retention in a working SWAT model.
Our approach to classifying wetlands relies on the use of a stream network shapefile, a sub-pixel water fraction (SWF) raster dataset, and a wetland polygon shapefile to validate the SWF data. Data for the SWF dataset should be on an annual timescale encompassing the study time series. Using ArcGIS Pro or similar spatial analysis software, SWF cells representing wetlands can be grouped into contiguous wetland units. The wetland_analysis.py code provided then classifies wetland units into connected if any wetland cell is within 30 m of the stream network, or disconnected if all wetland cells are greater than 30 m from the stream network. The code also classifies wetlands into low inundation or high inundation given the average value of SWF across the study domain. Thresholds can be set by the user. Wetland information from this analysis can then be imported into SWAT through the .res (connected wetland) or .pnd (disconnected wetland) input files.
We define disconnected wetlands through the pond/wetland (.pnd) module since SWAT recognizes them as hydrologically isolated from the stream network. Instead of receiving water, sediment and nutrient inputs directly from the stream network, disconnected wetlands receive a proportion of subbasin-scale runoff, sediment yield and nutrient loads, determined by the WET_FR parameter. The drainage_area.py code conducts spatial analysis in ArcGIS Pro using the Flow Direction and Watershed tools to 1) delineate flow paths surrounding each wetland and 2) quantify the contributing drainage area. This value was converted to the corresponding WET_FR for each subbasin. Users can modify the code to suit their study areas.
All codes were developed in Python. The user will can populate codes with their own relevant paths and information as indicated in the code.
